# Security Policy

## Supported versions

SportX is an early-stage static prototype. Security fixes are applied to the latest version on the default branch.

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue. Use the repository host's private vulnerability-reporting feature when available, or contact the repository maintainer privately.

Include reproduction steps, affected files or URLs, impact, and any suggested mitigation. Do not include real credentials or personal data in a report.

## Scope

The repository does not require secrets and has no server-side component. Reports involving unsafe DOM rendering, malicious upstream data, dependency or hosting configuration, and privacy-impacting behavior are welcome.
