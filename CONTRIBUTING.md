# Contributing to SportX

Thanks for helping improve SportX.

## Development

SportX is currently a static HTML, CSS, and JavaScript prototype with no build step.

```bash
python -m http.server 8080
```

Open `http://localhost:8080/` and verify changes at both desktop and mobile widths.

## Pull requests

- Keep changes focused and explain the user-facing outcome.
- Do not commit credentials, private data, generated logs, or local screenshots.
- Do not add league logos, player photos, broadcast media, or other third-party assets without a redistribution-compatible license and required attribution.
- Preserve the independent-project and prediction disclaimers.
- For data-source changes, document the source, its usage terms, failure behavior, and attribution requirements.

By submitting a contribution, you agree that it may be distributed under the repository's MIT License.
