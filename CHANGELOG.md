# Changelog

All notable changes to SportX will be documented in this file.

## [0.1.0] - 2026-07-14

### Added

- Responsive football and basketball schedule dashboard.
- Runtime ESPN scoreboard data adapter.
- Match, competition, region, team, and player filtering.
- Seven-day calendar, player watchlist, conflict hints, and lightweight match prediction.
- Light and dark themes.
- Open-source documentation, contribution guidance, security policy, and MIT License.
